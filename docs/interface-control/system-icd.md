# Interface Control Document (ICD): Distributed Mission Operations Baseline

## 1. Document Control & Purpose
* **System Baseline:** Version 1.2.0 (Path-Based Ingress & Helm Chart Topology)
* **Status:** Active Configuration
* **Description:** This document serves as the master interface contract between all core nodes, platform utilities, and micro-frontend shells within the repository. It freezes network paths, schema contracts, and error codes to allow decoupled subsystem development. All ingress traffic is standardized behind a path-routed gateway proxy, eliminating hardcoded service container ports from client runtime spaces. Compliance with these schemas is automatically enforced at runtime boundaries via Consumer-Driven Contract (Pact) tests.

---

## 2. Global Network & Observability Parameters
* **Primary Ingress Gateways:**
  - **Decentralized Local Dev (Compose):** `http://localhost` (Managed by unified Traefik container routing proxy)
  - **Integrated Kubernetes (k3d):** `http://localhost:8081` (Managed by Traefik ingress controller)
  - *Note: The runtime port delta is an intentional design boundary to support simultaneous container and cluster execution without local host socket collisions.*
* **Ingress Domain Prefix Routing:** 
  - Individual microservice application codebases remain completely agnostic of domain routing variables and listen on standard root endpoints (e.g., `/api/v1/*`). 
  - The Traefik edge proxies intercept external traffic, evaluate the structural domain prefix (e.g., `/topology`, `/compliance`, `/pdf`), and dynamically strip/rewrite the path prefix before forwarding traffic to backend service layers.
* **Primary Protocol:** Synchronous stateless communication occurs via HTTP/1.1 over JSON payloads.
* **Global Content-Type:** All HTTP requests and responses must communicate using `application/json` unless streaming files.
* **Traceability Requirement (Correlation ID):** Every transaction must carry a unique `X-Correlation-ID` header (UUIDv4) generated by the entry node to ensure complete distributed observability.

## 3. Path-Routed HTTP API Contracts (Core Verification Gate)

### 3.1. Topology Service Proxy (`/topology`)
Used by shells and process coordinators to retrieve organizational hierarchies, resolve asset custody projections from graph edges, and validate structural constraints.

* **Exposed Gateway Paths:**
  1. `GET /topology/api/v1/organizations`
  2. `GET /topology/api/v1/assets` (Supports query parameters: `?ownerId=string&excludeOwnerId=string`)
  3. `POST /topology/api/v1/authorizations`
  4. `GET /topology/api/v1/entities` (Returns full network graph projection of custody transfers)

* **Mandatory Headers:**
  * `X-Correlation-ID`: `string (UUIDv4)`
  * `Authorization`: `Bearer <Service-To-Service-JWT>`

### 3.2. Platform PDF Generator Proxy (`/pdf`)
A stateless platform utility wrapper that accepts a structured compliance data payload conforming to the DD-1149 template specification and outputs raw file binary data.

* **Exposed Gateway Paths:**
  1. `POST /pdf/api/v1/generate`

* **Request Schema (`DD1149TemplateDataSchema`):**
  ```json
  {
    "releasingEntityName": "string",
    "releasingAddressLine1": "string",
    "releasingAddressLine2": "string",
    "receivingEntityName": "string",
    "receivingAddressLine1": "string",
    "receivingAddressLine2": "string",
    "requisitionNumber": "string",
    "transferDate": "string (YYYYMMDD)",
    "items": [
      {
        "itemNumber": "number",
        "nomenclature": "string",
        "serialNumber": "string",
        "additionalNotes": "string (optional)",
        "unit": "string (default: EA)",
        "quantity": "number (default: 1)"
      }
    ]
  }
  ```

### 3.3. Compliance Document Ledger Proxy (`/compliance`)
Handles database metadata persistence logging and object store retrieval loops.

* **Exposed Gateway Paths:**
  1. `POST /compliance/api/v1/documents` – Streams cryptographically signed PDF document buffers to private MinIO storage buckets and logs tracking records into the PostgreSQL database ledger.
  2. `GET /compliance/api/v1/documents` – Queries and retrieves the complete metadata file history records from the relational persistence tier.

## 4. Standard System Network Error States
Every service operating in the cluster network interface must respond with a uniform schema when an error gate is triggered:

```json
{
  "errorCode": "string (e.g., SCHEMA_VALIDATION_FAILURE, ACCESS_DENIED)",
  "message": "string (Human readable description)",
  "correlationId": "string (UUIDv4)",
  "timestamp": "string (ISO 8601 UTC)"
}
```
