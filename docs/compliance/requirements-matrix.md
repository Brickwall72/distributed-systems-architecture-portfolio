# Requirements Traceability Matrix (RTM)

## Status

Original requirements dated 2026-08-15; implementation references and
assessments reviewed against the current custody-transfer system. These
assessments describe source and test coverage, not a formal compliance
certification or proof that tests passed in a deployed environment.

The original requirement wording is retained so differences in behavior are
visible. **Implemented** means the cited implementation addresses the
requirement; **partial / different** means it addresses some intent but does
not meet all of the original wording.

| **REQ-003b** | The process coordinator must intercept the inbound transaction token and transitively propagate it through all downstream HTTP headers and internal log statements. | [HTTP diagnostics](../../packages/express/src/middleware/requestDiagnostics/requestDiagnostics.ts) establish context; [NATS diagnostics](../../packages/messaging/src/diagnostics.ts) propagate it through immediate request/reply, including compliance's [PDF request](../../services/core/compliance-service/server/src/routes/templates/templates.route.ts).
